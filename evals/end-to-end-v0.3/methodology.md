# Methodology

The root evaluator gave a fresh Product Agent only the prescribed Korean idea prompt. The evaluator answered one material question at a time from a hidden bank, recorded unexpected legitimate questions, inserted the prescribed 7-day-to-30-day reversal after the initial decision existed, and withheld approval until an independent cross-artifact audit was clean.

The Product Agent used the frozen `joewrks-product-definition` Skill. It did not read this evaluation directory, the hidden bank, or prior evals. A separate auditor checked the compiled state and projections before approval. The root evaluator then approved exact revision 44 and digest, and reran both validators.

After closure, the root evaluator discovered actual Figma capabilities, created a dedicated design file, wrote native editable Auto Layout objects, read rendered screenshots, and compared them with the canonical screen contract. Tool discovery found no Figma Make create/run capability, so execution stopped at the required boundary.

Limit: invocation-time status checkpoints were observed throughout, but raw state files were not preserved at every requested 25%/50% checkpoint. The after-closure state is canonical; the missing raw snapshots are reported rather than reconstructed.
