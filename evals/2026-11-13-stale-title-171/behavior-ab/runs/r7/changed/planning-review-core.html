요청 폼 기획 검토 (revision 2)

로그인한 요청자가 요청 내용을 적어 유효한 요청을 제출하는 폼. rev 2는 요청 내용 칸의 글자 수 표시를 더한다.

이 문서는 기획의 축약 시각본입니다. 제품 UI 시안이나 visual-design authority가 아닙니다. 기준은 state.json입니다.

제품과 범위

  • 목표 GOAL-001: 요청자가 유효한 요청 제출을 끝낸다.
  • 사용자 USR-001: 로그인한 요청자.
  • 요구사항 REQ-001: 유효한 요청을 제출할 수 있다 (SURF-001 Request submission).
  • 해당 없음(EVD-900): 결제·파일 첨부·비동기·권한 구분·파괴적 동작 등. 인증만 활성.
